# Privacy Policy for Profile Media Downloader

**Effective date: August 13, 2026**

Profile Media Downloader is a browser extension that previews and downloads media already loaded and accessible on supported profile pages. This policy explains how the extension handles data.

## Data the extension handles

When the user opens the extension on a supported page, the extension may process the active page URL, profile username and display name, image and video elements, media URLs, and media-related response data. This information may include website content, browsing activity limited to the current supported page, and user-generated content displayed on that page.

The extension does not read or store passwords, authentication cookies, or access tokens. It does not collect financial information, health information, personal communications, form input, or precise location.

## How data is used

Page and media data is used only to identify the supported service, build the media preview shown to the user, remove duplicate items, and perform downloads the user requests. Download queue state and local preferences may be stored in Chrome local storage on the user's device.

## Data transmission and sharing

The extension has no developer-operated backend and does not transmit page content, media, browsing history, download history, or local preferences to the developer. It does not sell user data, use it for advertising, or share it with data brokers.

When the user requests a download, Chrome connects directly to the supported website or its media delivery network to retrieve the selected file. Those services process requests under their own privacy policies. The extension does not add a developer-controlled recipient to that communication.

## Data retention and deletion

Page scan results are held in browser memory while needed for the current interaction. Download queue state and settings remain in Chrome local storage until they are overwritten, cleared through browser extension data controls, or removed when the extension is uninstalled. Because no user data is stored on a developer server, the developer has no server-side copy to delete.

## Security

The extension uses packaged code and HTTPS resources exposed by supported services. It does not load remote executable code. Users should keep Chrome and the extension updated.

## Children's privacy and mature content

The extension is a general-purpose download utility, but one supported service is adult-oriented. The Chrome Web Store listing should therefore be marked as mature. The extension is not directed to children.

## User responsibilities

The extension does not unlock content, bypass paywalls, or provide access beyond the user's existing account permissions. Users are responsible for downloading only content they are entitled to save and for complying with applicable service terms, creator rights, and law.

## Limited Use

The use of information received from supported websites complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide the extension's disclosed media preview and download functionality; it is not used for personalized advertising, sold, or transferred to a developer-operated server, and is not made available for human reading by the developer.

## Changes

If the extension's data practices change, this policy and the Chrome Web Store disclosures will be updated before the changed practices are introduced. Material changes will be disclosed as required.

## Contact

For privacy or support questions, open an issue at https://github.com/ZeroMarker/profile-downloader/issues.
