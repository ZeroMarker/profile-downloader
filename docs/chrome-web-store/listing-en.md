# Chrome Web Store listing copy (English)

## Name

Profile Media Downloader

## Summary (132 characters or fewer)

Preview and batch-download accessible media already loaded on supported profile pages.

## Detailed description

Profile Media Downloader scans the supported profile page you are viewing, previews images and videos that have already loaded and are accessible to your current account, and lets you download selected items to your device.

Key features:

- Detects supported platforms and profile pages automatically
- Presents loaded images and videos in a preview grid
- Supports individual selection, select all, and batch download
- Deduplicates media and sorts it by time
- Keeps the download queue locally in Chrome, with up to three concurrent downloads by default
- Processes page data locally and does not upload page content or media to a developer-operated server

How to use:

1. Sign in to a supported service and open a profile page.
2. Scroll until the media you want has loaded.
3. Open the extension from the Chrome toolbar.
4. Select media and start the download.

Supported services are X / Twitter, TikTok, Instagram, Weibo, and OnlyFans. Website layouts change over time. If a scan is incomplete, load more content and try again.

This extension does not unlock content, bypass paywalls, or access media unavailable to your current account. Download only content you are entitled to save, and follow applicable service terms, creator rights, and local law. This extension is not affiliated with, sponsored by, or endorsed by any supported service.
