# Chrome Web Store 商店文案（简体中文）

## 名称

Profile Media Downloader

## 简短说明（132 字符以内）

预览并批量下载你在 X、TikTok、Instagram、微博和 OnlyFans 个人主页中有权访问且已加载的图片与视频。

## 详细说明

Profile Media Downloader 可扫描当前打开的受支持个人主页，展示页面中已加载且当前账号有权访问的图片和视频，并让你选择后下载到本地。

主要功能：

- 自动识别当前受支持的平台和个人主页
- 以网格方式预览图片和视频
- 支持单选、全选和批量下载
- 对重复媒体去重，并按时间排序
- 下载队列保存在浏览器本地，默认最多同时下载 3 个文件
- 所有解析均在浏览器本地完成，不向开发者服务器上传网页内容或媒体

使用方法：

1. 登录目标平台并打开一个个人主页。
2. 向下滚动，让需要保存的媒体加载到页面中。
3. 点击浏览器工具栏中的扩展图标。
4. 选择媒体并开始下载。

支持 X / Twitter、TikTok、Instagram、微博和 OnlyFans。平台页面结构可能随时变化；若扫描结果不完整，请先继续滚动加载内容后重试。

本扩展不会解锁内容、绕过付费墙或访问当前账号无权查看的媒体。请仅下载你有权保存的内容，并遵守适用的平台条款、创作者权利和当地法律。本扩展与所支持的平台没有隶属、赞助或认可关系。
